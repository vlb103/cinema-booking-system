# Реєстр ризиків Cinema Booking System

Основа: реєстр, запропонований AI-агентом (v1, 24 ризики), який автор перевірив і скоригував. ID ризиків збережено з v1.

## Що змінено порівняно з v1

1. Залишено 11 ризиків з 24, які найбільше стосуються проєкту. Решту не відкинуто як хибні, але для плану вони менш суттєві.
2. A-07 у v1 містив хибне твердження, що номери issues у матриці простежуваності не збігаються з фактичними. Матрицю перевірено скриптом, усі 36 рядків збігаються. Ризик до v2 не увійшов.
3. Пріоритет R-08 знижено з «Критичного» до «Високого». Критичним його робить лише припущення, що ядро тестуватимуть без СКБД, а цьому запобігає простий захід у T-01.

Пріоритет: ймовірність (Й) і вплив (В) за шкалою Н / С / В. В+В = критичний, В+С або С+В = високий, С+С = середній.
