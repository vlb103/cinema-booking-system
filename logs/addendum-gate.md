За `logs/api-gate.md` зміна контракту після API-GATE потребує доповнення до SRS і повторної перевірки. Після оновлення `docs/api/openapi.yaml` до версії 1.1.0 результати записуються тут.

| Перевірка | Результат |
| :--- | :--- |
| Валідація OpenAPI (Redocly CLI 1.25.0) | `openapi.yaml` 1.1.0 валідний, 0 помилок, 2 попередження (`info-license`, `no-server-example.com`) з обґрунтуванням в `logs/api-gate.md`. Попередження про відсутність 4xx у `GET /sessions` зникло, бо додано відповідь 400 |
| Сценарії `scenarios.md` на mock (Prism 5.12.0, `check_mock.py`) | 73 з 73. Усі 51 сценарій версії 1.0.0 збігаються, контракт для наявних клієнтів не змінився. Для N-41 (порожнє значення `date`) mock вважає параметр відсутнім, тому відповідь запитується заголовком `Prefer`, а перевірка переходить у тести сервера |
| Тести сервера з контрактом 1.1.0 | 286 з 286, перевірка `toSatisfyApiSpec` проходить з оновленим `openapi.yaml` |
