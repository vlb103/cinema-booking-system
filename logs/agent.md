# Coding Agent

Обраний кодинговий агент: Google Antigravity.

Клас інструменту:
AI coding agent, інтегрований у середовище розробки.

Спосіб доступу до репозиторію:
агент працює безпосередньо з файлами локального Git-репозиторію,
відкритого в середовищі Google Antigravity. Виконання операцій відбувається
у sandbox-середовищі, обмеженому робочим простором проєкту.

Операції, які агент може виконувати:
- аналізувати структуру проєкту;
- читати файли;
- створювати файли;
- редагувати файли;
- аналізувати код і текстові артефакти;
- пропонувати зміни;
- працювати з терміналом у межах робочого середовища.
